This book is structured to reflect the architecture described above.

The early chapters focus on RML and RCSS, treating the runtime and host as a given system. This allows us to explore layout, styling, and interaction without distraction.

Only when declarative UI reaches its limits do we cross the boundary into C++, examine the host responsibilities, and explain how RmlUi integrates with an application.

The second part of the book then explores the internals of RmlUi for readers who want to understand or extend the library itself.

With this foundation in place, we can now begin working directly with RmlUi’s UI language.
