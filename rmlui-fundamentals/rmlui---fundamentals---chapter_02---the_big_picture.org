** Where RmlUi Fits

RmlUi is a retained-mode UI framework that adopts the *declarative strengths* of
the web model without adopting the browser itself.

Its defining characteristics include:

- Declarative UI structure using RML
- Declarative styling using RCSS
- A retained element tree
- Explicit responsibility placed on the host application
- No built-in scripting engine
- Renderer-agnostic design

Unlike web-based systems, RmlUi does not expose a mutable DOM controlled by
scripts. Instead, interaction between the UI and the application is explicit and
intentional. This design prioritizes predictability, performance, and control.

---

*** 1.7 High-Level RmlUi Architecture

At a high level, RmlUi can be viewed as three layers:

- The *UI description layer* (RML and RCSS)
- The *RmlUi runtime*, which evaluates documents, computes layout, dispatches
events, and generates render data
- The *host application*, which provides rendering, input, timing, and file
access

Conceptually, the data flow looks like this:

RML / RCSS → RmlUi Runtime → Host Interfaces → Rendering Backend

The runtime is self-contained, but it depends on the host application for all
platform-specific functionality.
